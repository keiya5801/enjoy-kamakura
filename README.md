# EnjoyKamakura

鎌倉・七里ヶ浜・江の島をめぐるデートを盛り上げる、超インタラクティブなWebアプリです。
外部ライブラリ・ビルド不要のバニラHTML/CSS/JavaScriptで作られており、オフラインでも快適に動きます（現地は電波が不安定なこともあるため）。

## 使い方

`index.html` をブラウザで開くだけで動作します。ローカルサーバーを立てたい場合は：

```bash
cd EnjoyKamakura
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

スマホでその場で使う場合は、`index.html` をそのままブラウザで開くか、同じWi-Fiで上記サーバーを立ててスマホからアクセスしてください。

## 機能

- **ホーム** — 時間帯（朝／昼／夕方／夜）によって背景やあいさつが変化するアニメーション付きヒーロー画面
- **ルートマップ** — 鎌倉 → 七里ヶ浜 → 江の島の順に15スポットを紹介。タップで詳細（見どころ・豆知識・地図リンク）を表示
- **七里ヶ浜 日没カウントダウン** — 実際の天文計算（太陽位置アルゴリズム）でその日の日没時刻とカウントダウンをリアルタイム表示
- **デートビンゴ** — 9マスのミッションに挑戦。タテ・ヨコ・ナナメが揃うと紙吹雪演出。当日の記録はブラウザに自動保存
- **今日のおみくじ** — 二人の運勢・ラッキースポット・ラッキーフードをランダム診断
- **相性診断ミニゲーム** — 全8問、二人でスマホを回して回答し、シンクロ度を診断
- **フォトフレームメーカー** — 撮った写真を読み込み、スタンプを押して、日付入りのおしゃれなフレームで保存
- **波音BGM** — Web Audio APIで生成する環境音（外部音源ファイル不使用）

## ファイル構成

```
EnjoyKamakura/
├── index.html          エントリーポイント
├── css/style.css        スタイル定義
└── js/
    ├── spots-data.js    スポット・ミッション・診断コンテンツのデータ
    ├── sunset.js        日没時刻の計算ロジック
    ├── confetti.js       紙吹雪エフェクト
    ├── audio.js          波音BGM生成
    └── app.js            画面制御・全機能のロジック
```

## 技術メモ

- 外部CDN・APIキー不要。すべてクライアントサイドで完結
- スポット詳細の「地図アプリで開く」リンクのみ、タップ時にGoogleマップへ遷移
- デートビンゴの達成状況は当日分のみ `localStorage` に保存（日付が変わるとリセット）
